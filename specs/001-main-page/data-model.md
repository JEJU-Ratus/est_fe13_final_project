# 데이터 모델: 메인 페이지

본 문서는 메인 페이지가 다루는 폼·요청·UI 상태만 정의한다. 데이터베이스 테이블과
Supabase 모델은 범위에 포함하지 않는다.

## 요약 생성 입력

| 필드 | 의미 | 규칙 |
|------|------|------|
| `topic` | 요약할 주제 | 앞뒤 공백 제거 후 1~200자 |
| `isPasswordEnabled` | 비밀번호 보호 사용 여부 | Boolean, 기본값 `false` |
| `password` | 선택적 보호 비밀번호 | 사용 시 숫자 4자리, 미사용 시 전송 제외 |

### 검증 규칙

1. `topic.trim()`이 비어 있으면 유효하지 않다.
2. 정리된 `topic`이 200자를 초과하면 유효하지 않다.
3. `isPasswordEnabled`가 `true`이면 `password`는 숫자 4자리여야 한다.
4. `isPasswordEnabled`가 `false`이면 `password`의 현재 표시 값과 관계없이 전송 데이터에서 제외한다.

## 생성 요청 상태

| 상태 | 의미 | 사용자 표시 | 허용되는 다음 상태 |
|------|------|---------------|----------------------|
| `idle` | 요청 전 또는 상태 정리 후 | 요청 모달 없음 | `submitting` |
| `submitting` | 요약 생성 진행 중 | 로딩 모달, 중복 제출 차단 | `succeeded`, `failed` |
| `succeeded` | 요약 식별자 수신 | 해당 요약 상세로 이동 | 페이지 이동으로 종료 |
| `failed` | 생성 요청 실패 | 재시도·닫기가 있는 오류 모달 | `submitting`, `idle` |

## 모달 상태

| 모달 | 표시 조건 | 종료 또는 이동 |
|------|-----------|---------------|
| 로그인 권장 | 비로그인 생성 또는 마이페이지 시도 | 로그인, 전체 요약, 닫기 |
| 준비 중 | 퀴즈 카드 선택 | 닫기 |
| 로딩 | 생성 요청 진행 | 성공 이동 또는 오류 전환 |
| 오류 | 생성 요청 실패 | 재시도 또는 닫기 |

## 요약 생성 결과

| 필드 | 의미 | 규칙 |
|------|------|------|
| `summaryId` | 생성된 요약의 고유 식별자 | 성공 결과에서 비어 있지 않음 |

`summaryId`는 성공 후 요약 상세 경로를 구성하는 데만 사용한다. 형식과 저장 규칙은
서버 계약에서 정의한다.
