# 상호작용 계약: 메인 페이지

이 계약은 메인 페이지가 필요로 하는 논리적 입출력을 정의한다. API 경로, HTTP 메서드,
Supabase 클라이언트, Server Action 등의 구현 방식은 정의하지 않는다.

## 인증 상태 계약

메인 페이지는 사용자가 로그인했는지 판별할 수 있어야 한다.

| 상태 | 생성 시도 | 마이페이지 시도 |
|------|-----------|----------------------|
| 로그인 | 입력 검증 후 요약 생성 요청 | 마이페이지로 이동 |
| 비로그인 | 요청 없이 로그인 권장 모달 | 이동 없이 로그인 권장 모달 |

인증 확인 중·실패 상태가 필요하다면 인증 명세에서 추가한다.

## 요약 생성 요청 계약

### 입력

| 항목 | 필수 | 규칙 |
|------|------|------|
| 주제 | 예 | 공백 정리 후 1~200자 |
| 비밀번호 사용 여부 | 예 | `true` 또는 `false` |
| 비밀번호 | 조건부 | 사용 여부가 `true`일 때만 숫자 4자리 |

### 성공

- 비어 있지 않은 요약 식별자를 제공한다.
- 페이지는 성공 결과를 받으면 `/summary/{summaryId}`로 이동한다.

### 실패

- 페이지가 사용자에게 표시할 수 있는 실패 정보를 제공한다.
- 페이지는 오류 모달에서 같은 유효한 입력을 재시도하거나 모달을 닫을 수 있게 한다.
- 실패 코드와 사용자 메시지 문구는 서버 계약이 확정될 때 추가한다.

## 화면 이동 계약

| 행동 | 대상 |
|------|------|
| 로그인 선택 | `/login` |
| 전체 요약 노트 선택 | `/summary` |
| 성공한 요약 확인 | `/summary/{summaryId}` |
| 로그인 사용자의 마이페이지 선택 | `/mypage` |
| 퀴즈 선택 | 이동 없이 준비 중 모달 |
| 배너 선택 | 확정된 URL이 있을 때만 해당 페이지 |

## 공통 UI 의존성

| 의존성 | 메인 페이지가 필요로 하는 동작 |
|----------|-------------------------------------|
| Header | 로그인 상태에 맞는 공통 탐색 표시 |
| Banner | 이미지·대체 텍스트 표시, URL이 있을 때 선택 제공 |
| SuggestLoginModal | 로그인, 전체 요약, 닫기 행동 |
| PreparingModal | 준비 중 안내와 닫기 행동 |
| QuickLinkCard | 제목·아이콘·선택 행동 표시 |

이 컴포넌트들의 구체적 props와 Header 레이아웃은 공통 컴포넌트 명세에서 확정한다.
