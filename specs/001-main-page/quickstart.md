# 검증 안내: 메인 페이지

## 전제 조건

- 의존성이 설치되어 있다.
- 메인 페이지 구현이 완료되어 있다.
- 로그인·비로그인 상태와 요약 생성 성공·실패 결과를 재현할 수 있다.
- 인증·서버 연결이 아직 없다면 해당 시나리오는 계약 확인으로 보류하고 UI 입력·모달·
  이동 범위만 검증한다.

## 정적 검증

```bash
npm run lint
npm run build
```

두 명령이 오류 없이 종료되어야 한다. 추가 테스트 패키지는 도입하지 않는다.

## 실행

```bash
npm run dev
```

브라우저에서 `/`를 열고 아래 시나리오를 순서대로 확인한다.

## 시나리오 1: 입력 검증

1. 빈 주제로 생성을 시도한다.
   - 예상: 주제 필수 안내가 나오고 요청은 시작되지 않는다.
2. 공백만 있는 주제와 201자 주제를 각각 제출한다.
   - 예상: 모두 거부되고 문제 항목을 확인할 수 있다.
3. 비밀번호 사용을 선택하고 빈 값, 3자리, 문자가 섞인 4자리를 각각 입력한다.
   - 예상: 모두 거부된다.
4. 숫자 4자리를 입력한다.
   - 예상: 비밀번호 검증을 통과한다.
5. 비밀번호 사용을 해제한다.
   - 예상: 입력이 비활성화되고 비밀번호는 요청 데이터에서 제외된다.

## 시나리오 2: 로그인 사용자의 생성

1. 로그인 상태에서 유효한 주제를 제출한다.
   - 예상: 로딩 모달이 표시되고 중복 제출이 차단된다.
2. 성공 결과와 요약 식별자를 제공한다.
   - 예상: 로딩 모달이 종료되고 해당 요약 상세로 이동한다.
3. 다시 요청하고 실패 결과를 제공한다.
   - 예상: 실패 안내, 재시도, 닫기가 있는 오류 모달이 표시된다.
4. 재시도와 닫기를 각각 확인한다.
   - 예상: 재시도는 같은 유효한 입력으로 다시 요청하고, 닫기는 입력을 유지한 채 모달만
     닫는다.

## 시나리오 3: 비로그인 보호

1. 비로그인 상태에서 생성을 시도한다.
   - 예상: 요청 없이 로그인 권장 모달이 열린다.
2. 모달의 로그인, 전체 요약, 닫기를 각각 확인한다.
   - 예상: 각각 `/login`, `/summary`, 현재 페이지 유지로 처리된다.
3. 비로그인 상태에서 마이페이지 카드를 선택한다.
   - 예상: 이동 없이 같은 로그인 권장 모달이 열린다.

## 시나리오 4: 바로가기와 배너

1. 전체 요약 노트 카드를 선택한다.
   - 예상: `/summary`로 이동한다.
2. 퀴즈 카드를 선택하고 모달을 닫는다.
   - 예상: 준비 중 모달이 열린 후 닫힌다.
3. 로그인 상태에서 마이페이지 카드를 선택한다.
   - 예상: `/mypage`로 이동한다.
4. 배너 URL이 없는 상태에서 배너을 선택한다.
   - 예상: 임의 페이지로 이동하지 않는다.
5. 확정된 배너 URL을 제공하고 배너을 선택한다.
   - 예상: 지정된 페이지로 이동한다.

## 완료 판정

- `FR-001`~`FR-017`의 관련 시나리오가 모두 통과한다.
- 필수 입력 누락과 비로그인 접근이 요청으로 이어지지 않는다.
- 생성 중 중복 요청이 발생하지 않는다.
- 임의의 인증·서버·배너 구성이 추가되지 않는다.
